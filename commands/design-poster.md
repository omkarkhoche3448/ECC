Launch the **poster-designer** agent to create premium, visually stunning product launch posters and marketing banners.

## What it does

Creates pixel-perfect HTML/CSS posters with:
- 30+ design concepts (holographic cards, movie posters, blueprints, neon signs, before/after splits, convergence visuals, and more)
- Premium effects (glassmorphism, mesh gradients, multi-layer glow, conic borders, noise texture)
- Actual product assets (logos, screenshots, company logos, illustrations)
- Export-ready dimensions (1080x1350 LinkedIn, 1080x1080 Instagram, custom)

## Usage

```
/design-poster
/design-poster for LinkedIn launch
/design-poster movie poster style for [product]
/design-poster 5 versions for [product] launch
```

## The agent will:

1. **Explore** your codebase for product assets (logos, screenshots, illustrations, brand colors)
2. **Ask** about platform, style preference, and key messaging
3. **Design** one or more poster variants with completely unique concepts
4. **Deliver** ready-to-export HTML files with export instructions
